MediFlow IMS - Setup Instructions

1. Create a virtual environment (first setup only)
   python -m venv venv

2. Activate the virtual environment (Windows PowerShell)
   .\venv\Scripts\Activate.ps1

3. Install dependencies
   pip install -r requirements.txt

4. Start the application
   streamlit run app.py

5. Open the local application
   http://localhost:8501

Create an account from the Sign In page. Passwords must be at least 8 characters.
The SQLite database is created automatically at data/mediflow.db.
Press CTRL+C in the terminal to stop the server.
